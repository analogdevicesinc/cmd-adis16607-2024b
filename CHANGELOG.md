# Changelog

All notable changes to this release package are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0-ga] - 2026-11-24

### Added

- First general-availability release of the ADIS16607-2 Simulink model toolbox
  package for MATLAB R2024b, distributed as `ADIS16607_IMU_R2024b`. For MATLAB
  R2025b, install the `ADIS16607_IMU` toolbox instead; it contains the same model.
- End-user documentation set: quickstart, interfaces, behavior, behavior reference,
  fidelity, and limitations.
- Getting Started guide and packaged example delivered as Live Scripts
  (`getting_started.mlx`, `accel_mission_profile_example.mlx`).
- Example launch support through `ADIS16607.openExample()` for quick onboarding.
